# Yap’s developer portfolio

A static GitHub Pages portfolio featuring Dinnerplate.party, CacheBuddy, and FlowDesk.

## Preview locally

Run `python3 -m http.server 8000 --directory docs` from the repository root, then open http://localhost:8000. The site has no build step or runtime dependencies.

GitHub Pages publishes the `/docs` directory from `main`. All site assets are served locally. The [site notice](docs/site-notice.html) describes privacy, accessibility, and credits.
