Site Notice

Privacy

This portfolio uses no analytics, advertising, contact forms, tracking cookies, or browser storage. The site uses system fonts and serves its images directly. It makes no requests to third-party services while you browse. Email and external project links open services with their own privacy practices.

GitHub Pages hosts the site. GitHub logs visitors’ IP addresses for security. External sites linked from the portfolio have their own privacy practices. GitHub Privacy Statement

Accessibility

The portfolio supports keyboard navigation, visible focus, text zoom, and reduced-motion preferences. Its decorative Matrix background responds to scrolling and briefly eases to a stop afterward. Use the Matrix button to pause it; it starts paused when your device requests reduced motion. The site remains usable without JavaScript. You can report an accessibility issue or send feedback through the portfolio issue tracker. Issues are public.
